# Структура исходного кода

- `documents` — типы документов и сценарии, которым нужен прямой доступ к `this.ExpectedLines`.
- `operations` — исполняемая клиентская и серверная логика, разделенная по назначению.
- `tables` — определения таблиц, их полей и ключей.
- `containers` — типы контейнеров и правила распознавания штрихкодов.
- `expand` — дополнительные поля стандартных типов платформы.

Файлы в `operations`:

- `ReceivingNavigation.erst` — главное меню и подтверждение выхода.
- `ContainerScanning.erst` — сканирование и проверка коробки.
- `ReceivingBoxSelection.erst` — выбор коробки для документа.
- `ReceivingBoxRegistry.erst` — серверные операции над таблицей рабочих коробок.

Основной цикл приемки остается в `documents/Receiving.erst`
